# MV-P0.16 — Final Multiscale Variable Matrix

**Status:** FINAL DOCUMENTARY CONSOLIDATION
**Runtime catalog:** NOT IMPLEMENTED

## 1. Final architecture

```text
SpatialScope
  → SpatialLocation / Context
  → ScaleVariableProfile
  → Canonical Variable Requirements
  → Source Requirements
  → Available / Missing Data
  → Capability Resolution
  → Analysis
  → Derived Metrics
  → Evaluation
  → Alternatives / Trade-offs
  → HumanReview
  → Decision
```

This is a conceptual architecture. Acquisition, suggestion, derivation, and capability resolution never become a Human Decision automatically.

## 2. Matrix legend

`PRESENT`, `MISSING`, `UNKNOWN`, `NOT_AVAILABLE`, and `NOT_APPLICABLE` are future data-state distinctions. Acquisition paths may include `USER_INPUT`, `MAP_SELECTION`, `PROJECT_DOCUMENT`, `GIS`, `EXTERNAL_SOURCE`, `DERIVATION`, and `ASSUMPTION` where constitutionally allowed.

| Profile field | Documentary meaning |
|---|---|
| Requirement by scale | REQUIRED, RECOMMENDED, OPTIONAL, or NOT_APPLICABLE |
| Temporal semantics | observation/reference/frequency/scenario/validity/retrieval |
| Spatial support | design scale distinct from dataset resolution |
| Provenance requirement | source, evidence, method, capture/retrieval |
| Source requirement | class, authority, coverage, resolution, validation |
| Location dependency | independent, contextual, or required |
| Capability relationship | family and requirement state |
| Derivation dependency | declared prerequisites only |
| Conditional applicability | typology, context, stage, data, objectives |
