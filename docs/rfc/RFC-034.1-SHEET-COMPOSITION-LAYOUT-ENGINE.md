# RFC-034.1 — Sheet Composition & Layout Engine

**Estado:** IMPLEMENTED
**Módulo:** `src/sicl/layout/`
**Propósito:** calcular y validar la composición geométrica de láminas sin dibujar ni generar PDF.

## 1. Separación arquitectónica

El motor recibe formatos, márgenes, zonas y elementos geométricos, calcula bounding boxes y emite reportes JSON. No renderiza, no crea PDF/PNG, no modifica `BIMModelSnapshot` y no crea `Decision`.

El renderizado continúa siendo responsabilidad de RFC-030/RFC-034.

## 2. Módulos

- `sheet_format.py`: formatos A4, A3, A2, A1 y A0, orientación horizontal/vertical.
- `sheet_zone.py`: `SheetZone`, `LayoutElement` y bounding boxes.
- `sheet_grid.py`: grilla de columnas, márgenes y coordenadas de contenido.
- `layout_engine.py`: `SheetLayout`, cálculo y validación.
- `collision.py`: intersección entre bounding boxes y `allowed_overlap`.
- `margin_validator.py`: márgenes, truncaciones y zonas obligatorias.
- `layout_report.py`: `LayoutCollision`, `LayoutValidationResult` y reporte textual.
- `case_study.py`: caso verificable de cinco láminas Casa Nido.
- `http_api.py`: servicio HTTP independiente del Core.

## 3. CLI

```text
/LAYOUT FORMAT SET <format> [--orientation=H|V]
/LAYOUT MARGINS SET --top=<mm> --bottom=<mm> --left=<mm> --right=<mm>
/LAYOUT ZONES DECLARE <layout_id> --zones=<json>
/LAYOUT ZONES SHOW <layout_id>
/LAYOUT CALCULATE <layout_id> --elements=<json>
/LAYOUT VALIDATE <layout_id>
/LAYOUT SHOW <layout_id>
/LAYOUT REPORT <layout_id>
/LAYOUT EXPORT <layout_id> --format=JSON
```

Implementación: `scripts/layout_cli.py`.

## 5. Validación Casa Nido de Campo

- Cinco láminas A3 horizontal.
- Márgenes: superior 20 mm, inferior 20 mm, izquierdo 25 mm, derecho 25 mm.
- Zonas: título, cajetín, dibujo, norte, escala y notas.
- Elementos con bounding box explícito.
- Resultado: cinco láminas válidas, cero colisiones, cero violaciones de márgenes.

Reporte: `docs/reference/RFC0341_CASA_NIDO_LAYOUT_REPORT.json`.
